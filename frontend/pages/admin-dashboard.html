      Admin Guide

      Slot naming and generation

      Recommended Format F1-S1, F1-S2, F2-S1

      Use F for floor and S for slot number. The system sorts numeric parts properly, so F1-S10 appears after F1-S9.

      Existing Format L1, L2, L10

      Older labels still work and now sort naturally instead of text sorting as L1, L10, L2.

      Bulk Creation Use 10 to create F1-S1 to F1-S10

      Recommended maximum is 100 slots per generation so the floor stays easy to review.
